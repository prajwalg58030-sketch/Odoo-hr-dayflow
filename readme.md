# 🌊 DAYFLOW HRMS
> **"Every workday, perfectly aligned."**

DAYFLOW HRMS is a comprehensive, enterprise-grade Human Resource Management System built to digitize and streamline core HR operations. Designed with a clean, modern SaaS architecture, it manages everything from automated employee onboarding and attendance tracking to complex payroll calculations and role-based access control.

---

## 🏗️ Technology Stack

**Frontend**
* HTML5 & CSS3 (Custom responsive design system, CSS variables)
* Vanilla JavaScript (ES6+ modular architecture)
* *Note: Deliberately built without heavy frontend frameworks (React/Angular) for maximum performance and direct DOM control.*

**Backend & API**
* Python 3.x
* Flask (Application Factory Pattern)
* SQLAlchemy (ORM) & psycopg2-binary
* JWT (JSON Web Tokens) & bcrypt (Security)

**Database**
* PostgreSQL (Strict relational integrity, constraints, and JSONB for dynamic salary structures)

---

## ✨ Core Modules & Features

### 🔐 Authentication & Security
* **Automated Identity:** System auto-generates unique Employee Login IDs (e.g., `OIJODO20260001`) and secure temporary passwords.
* **Role-Based Access Control (RBAC):** Strict separation between `Admin/HR` and `Employee` privileges enforced at the API route level.
* **Email Verification:** Token-based account activation architecture.

### ⏱️ Time & Attendance Tracking
* **Server-Authoritative Clock:** Check-in/Check-out timestamps are generated by the backend to prevent client-side manipulation.
* **Hours Calculation:** Automated daily tracking of standard "Work Hours" vs "Extra Hours".
* **Dashboard Analytics:** Live status indicators (Present, Checked Out, Absent, On Leave).

### 🏖️ Time Off & Leave Management
* **Leave Allocation:** Configurable balances for Paid Time Off, Sick Leave, and Unpaid Leave.
* **Approval Workflows:** HR dashboards to approve/reject requests with mandatory comment trails.
* **Document Handling:** Secure file upload for medical certificates with strict MIME-type validation.

### 💰 Payroll & Salary Engine
* **Dynamic Components:** Highly configurable salary structures supporting Base, HRA, LTA, PF, Professional Tax, and Performance Bonuses.
* **Attendance Integration:** Payable days are automatically calculated based on attendance records and approved unpaid leaves.
* **Data Privacy:** Salary endpoints strictly restrict visibility to authorized HR personnel.
